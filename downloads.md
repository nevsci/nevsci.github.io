### Windows SmartScreen notice

RYBA's Windows programs are currently unsigned. Microsoft Defender SmartScreen may warn that the publisher is unknown. Obtain RYBA from the official site and verify its SHA-256 checksum; where Windows permits it, users who trust the verified file may choose More info → Run anyway. Do not disable SmartScreen globally.

### Verify your download (SHA-256)

[Download SHA-256 checksums](../assets/projects/RYBA/RYBA_1.39.1_SHA256SUMS.txt) for all five current packages. On Windows use `Get-FileHash -Algorithm SHA256 filename.exe`; on Linux use `sha256sum filename` and on macOS use `shasum -a 256 filename`. Matching a published hash confirms file integrity, not the absence of malware.
